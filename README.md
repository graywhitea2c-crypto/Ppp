# GPS Tempo Player — Pro UI

پروژه‌ی اندروید Kotlin با رابط تیره‌ی مدرن و تم بنفش/صورتی.

## قابلیت‌ها
- انتخاب چند فایل صوتی از حافظه‌ی دستگاه
- لیست پخش و کنترل‌های قبلی/بعدی/پخش/مکث
- تغییر سرعت پخش بر اساس سرعت GPS
- تنظیم حداقل و حداکثر سرعت پخش
- تعیین سرعت GPS شروع و سقف سرعت
- فیلتر نرم‌سازی GPS و کنترل حساسیت و زمان هموارسازی
- ساخت خودکار APK با GitHub Actions

## ساخت APK در GitHub
1. فایل ZIP را استخراج کنید و محتویات را به یک repository در GitHub بفرستید.
2. تب **Actions** را باز کنید و workflow به نام **Android APK Build** را اجرا کنید یا یک commit ارسال کنید.
3. از اجرای موفق workflow، بخش **Artifacts** فایل `GPS-Tempo-Player-APK` را دریافت کنید.

APK خروجی نسخه‌ی Debug است و برای انتشار عمومی باید نسخه‌ی Release را با کلید امضای خودتان امضا کنید.

## نکته
این نسخه نمونه‌ی اولیه‌ی کاربردی است؛ هنگام تست GPS، مجوز موقعیت مکانی را بدهید. پخش پس‌زمینه با سرویس foreground و اعلان رسانه‌ای هنوز اضافه نشده است.
