# GPS Tempo Player 1.2.0

نسخه با سرویس MediaSession برای پخش پس‌زمینه، ذخیره تنظیمات و لیست پخش، و ورود دستی حداقل/حداکثر سرعت پخش و سرعت حرکت.

محتویات ZIP را مستقیماً در ریشه مخزن GitHub قرار دهید. از Actions فایل Debug APK را دانلود کنید. این سورس باید پیش از انتشار روی دستگاه واقعی آزمایش شود؛ محدودیت‌های باتری سازنده گوشی ممکن است بر GPS در پس‌زمینه اثر بگذارد.
