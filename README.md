# Tempo Player — اصلاحات نسخه جدید

- رابط تیره با رنگ‌های فیروزه‌ای و بنفش و چیدمان قابل پیمایش.
- دکمه‌های قبلی، توقف، بعدی و پخش/مکث در صفحه برنامه.
- افزودن چند فایل صوتی یا اسکن یک پوشه انتخاب‌شده و افزودن فایل‌های صوتی داخل آن و زیرپوشه‌ها.
- فهرست پخش همگام‌سازی می‌شود تا فایل‌های جدید در صف پخش و کنترل‌های رسانه‌ای سیستم دیده شوند.
- حذف گزینه «حساسیت GPS»؛ هموارسازی سرعت با ضریب ثابت انجام می‌شود. کنترل سرعت پخش مبتنی بر GPS همچنان فعال است.
- حذف قفل بیدارباش زمان‌دار سه‌ساعته که می‌توانست باعث قطع ناگهانی پخش طولانی شود؛ پخش پس‌زمینه با MediaSessionService مدیریت می‌شود.
- کنترل‌های استاندارد اعلان رسانه از Media3 می‌آیند؛ نمایش قبلی/بعدی به وجود صف چندفایلی وابسته است.

## ساخت
پروژه با Android Gradle Plugin 8.7.3 و Kotlin 2.0.21 پیکربندی شده است. فایل ZIP را در یک محیط Android/Gradle باز کنید و `assembleDebug` را اجرا کنید. در این محیط، Gradle در دسترس نبود؛ بنابراین ساخت APK و آزمایش روی دستگاه انجام نشده و قبل از انتشار باید روی دستگاه واقعی بررسی شود.
